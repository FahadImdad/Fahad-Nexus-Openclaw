## Specific Mistakes Identified

### True/False/Not Given
- Writes TRUE too often — sees same word in passage and statement, assumes TRUE
- Fix: Ask "does passage make THIS EXACT CLAIM?" not just "does passage mention this topic?"
- Rule: When unsure → default to NOT GIVEN (not TRUE)

### Fill in Blank
- Finds the right sentence but grabs the wrong word
- Example: wrote "society" instead of "druids", wrote "plants" instead of "engineering"
- Fix: After filling blank, read full sentence — does it make sense? Yes = keep. No = find another word.
- Method: Find 2 key words in blank sentence → scan passage → answer is next to those words

### Multiple Choice
- Got 0/6 — comprehension too weak for this type
- Strategy: eliminate 2 obviously wrong answers, guess from remaining 2

## Strategies Given
- Questions first — NEVER read passage first
- 18 min Passage 1 / 20 min Passage 2 / 22 min Passage 3
- 90 seconds max per question — guess and move on
- Never leave blank — always guess
- Passage 1 is easiest — maximize marks there
- For process sentences use: [thing] is [action] to/in order to [result]
